# Personal Hobby Site

My personal portfolio and website, built to showcase my experience, projects and the things I enjoy making outside of work.

## Built with

* HTML5
* CSS3
* Vanilla JavaScript
* Git & GitHub
* Cloudflare Pages

## What's included

* About me
* Personal and software projects
* Crafting & gardening projects
  * Blog posts
* Downloadable CV

## Development

This is a static website with no build process or framework required.

To run it locally, simply open `index.html` in a browser or serve the project with a local web server.

## Deployment

The site is hosted using Cloudflare Pages and deployed automatically from the `main` branch on GitHub.
